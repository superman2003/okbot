# okbot

Личный ИИ-помощник с подключением к выбранному сервису моделей через собственный URL и ключ API.

## Настройка сервиса моделей

1. Откройте форму первого запуска или настройку своего сервиса в разделе моделей.
2. Укажите **API Base URL** и **API Key**, например `https://your-api.example/v1`.
3. Загрузите список моделей и выберите модель. Если списка нет, введите точный ID вручную.
4. Проверьте модель. Будет отправлен короткий запрос; возможна обычная плата за API.
5. Сохраните настройки. Подключение и модель по умолчанию хранятся локально и сохраняются после перезапуска.

Поддерживается **API, совместимый с OpenAI Chat Completions**. Требуется `/chat/completions`; `/models` необязателен. Сервисы, предлагающие только другие протоколы, через эту форму напрямую не работают. К корневому URL добавляется `/v1`, пользовательский путь сохраняется.

Запросы отправляются выбранному сервису; функции, лимиты и оплата зависят от него и модели. Сохранены подключения официальных провайдеров и OKINTO. Модель отдельных ботов и бесед нужно переключать отдельно.

## Возможности и изменения

- Собственные URL и ключ, список моделей, выбор, ручной ID и проверка модели.
- Отдельная маршрутизация источников с сохранением ID и пространств имён моделей.
- Локальное хранение подключения и модели; интерфейс показывает только окончание сохранённого ключа.
- Унаследованы боты, роли, рабочие папки, память, инструменты и фоновые задачи.
- Сохранены чат приложения, WeChat, Feishu и другие реализации каналов.
- Установщик Windows, локальные скрипты запуска и проверка упакованной среды.

Инструменты, управление компьютером и мультимодальность зависят от модели и способа подключения.

## Запуск из исходников

Требуются **Node.js 22.13+** и **Go 1.26.8+**. Setup подготовит шлюз и среду агента.

```bash
git clone https://github.com/superman2003/okbot.git
cd okbot
npm ci
npm run setup
npm run build
npm start
```

Консоль по умолчанию: `http://127.0.0.1:3600/`. После установки зависимостей и компиляции в Windows также можно запустить `Start-Okbot.cmd`: порт по умолчанию 3610, страница открывается с токеном доступа.

Данные исходной версии находятся в `data/`, настольной версии Windows — в `%APPDATA%\anymodel bot\data`. Ключи, беседы, зависимости и результаты сборки не включаются в репозиторий.

## Сборка установщика Windows

В Windows x64:

```bash
npm run dist -- --win nsis --x64
```

Результат записывается в `release/`. Для разработки настольной версии используйте `npm run electron:dev`. Загружаются закреплённые версии компонентов; SHA256 Cua Driver проверяется.
